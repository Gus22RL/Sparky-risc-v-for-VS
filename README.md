# Sparky-risc-v-for-VS
Sparky RISC-V is a Visual Studio Code extension that lets you edit, run and debug RISC-V assembly inside VS Code. It runs the unmodified rars1_6.jar (RARS 1.6, by TheThirdOne) as its simulator, so assembling and executing programs behaves exactly like RARS. Requires Java 8 or later.
